## 1. 私たちについて

本プライバシーポリシーは、**Journeo**（以下「**Journeo**」、「**当社**」、「**私たち**」）によって発行されています。

Journeoは、iOSおよびAndroid向けに提供されるAI支援・地図中心の旅行計画アプリケーション、および https://journeo.ai における関連サービス（総称して「**本サービス**」）です。

本プライバシーポリシーは、当社が収集する個人データ、その利用方法、共有先、保持期間、およびお客様の選択肢について説明するものです。Journeoのモバイルアプリ、API、およびウェブサイトに適用されます。

本ポリシーに同意されない場合は、本サービスのご利用をお控えください。

## 2. 適用範囲と役割

当社は、Journeoのアカウント、旅行、設定、および関連機能を提供するために処理される個人データの**データ管理者（管理者）**として行動します。

一部の処理は、当社の指示に従って行動する処理者（ホスティング、認証、分析、クラッシュレポート、地図、AIモデルプロバイダーなど）によって実行されます。これらの処理者についてはセクション6.1に記載されています。

本ポリシーは以下の開示要件を満たすことを目的としています：

- Apple App Store（プライバシーポリシーURLおよびアプリのプライバシー栄養ラベル）

## 3. 収集する個人データ

当社はJourneoの運営に必要な情報のみを収集します。お客様による本サービスの利用状況に応じて、以下が含まれる場合があります：

### 3.1 アカウントおよびプロフィール情報

- メールアドレス（パスワードはハッシュ化された形式でのみ保存され、平文のパスワードを当社が閲覧することはありません）
- ユーザー名（一意で、友だちの検索や追加に使用されます）
- 表示名 / フルネーム
- プロフィール写真（アバター）
- タイムゾーン
- 希望する言語 / 地域設定
- 当社システムによって生成されたアカウント識別子

### 3.2 旅行および作成されたコンテンツ

- 旅行のタイトル、目的地（都市/国）、日程、カバー画像、旅行ステータス
- 旅行の好み（スタイル、ペース、食事、予算帯、興味・関心、アクセシビリティ設定）
- 日程計画と立ち寄り先（追加したスポット、メモ、順序、予約関連リンク）
- 持ち物リスト、追加したフライト情報、旅程の費用
- フレンドシップ / 旅行メンバーおよび役割（オーナー、編集者、閲覧者）
- 日程を作成・調整するために送信されたプランナーチャットメッセージおよびプロンプト
- 生成された提携予約リンクを開いたときのアフィリエイトクリックイベント

### 3.3 位置情報データ

お客様の同意に基づき、**アプリの使用中**に以下の目的でおおよその位置および/または正確なデバイスの位置情報を収集する場合があります：

- 地図上にお客様の現在地を表示する
- 現在地に合わせて旅行プランをカスタマイズする
- 音声プランニングにおける都市検出などのサポート機能
- **旅行仲間とのリアルタイム位置情報共有** — **お客様自身**が特定の旅行に対して時間制限付きのライブ共有セッションを開始した場合のみ（例：1/4/8時間、または終日まで）。このセッションが有効でアプリがフォアグラウンドにある間、お客様のおおよそ/正確な座標は**その旅行**の他のメンバーに表示されます。共有をオフにした場合、セッション期限が切れた場合、またはアプリがバックグラウンドに移行した場合に共有は停止します。この機能のために「常に許可」やバックグラウンド位置情報の権限を**要求することはなく**、旅行メンバー以外や広告目的でリアルタイム位置情報を共有することはありません。

位置情報の利用は**使用時のみ**のアクセスとバランスの取れた精度で設計されています。広告目的でバックグラウンドでお客様の位置情報を継続的に**追跡することはありません**。

デバイスの設定で位置情報の権限を拒否または取り消すことができます。

**お客様の位置情報は分析プロバイダーに送信されません。** 分析イベントには旅行の目的都市名などの場所名が含まれる場合がありますが（セクション3.7）、座標が含まれることはありません。

### 3.4 マイクと音声

お客様の同意に基づき、音声による旅行計画を可能にするため、マイクおよびデバイス/システムの音声認識機能にアクセスする場合があります。音声データは計画のためのテキスト変換にのみ使用され、広告目的で録音を販売することはありません。

### 3.5 カメラおよびフォトライブラリ

お客様の同意に基づき、プロフィール画像の設定のためにカメラまたはフォトライブラリにアクセスする場合があります。選択された画像はストレージにアップロードされ、アカウントに関連付けられます。

### 3.6 通知

通知を有効にした場合、旅行に関する通知やプロダクトからのお知らせを配信するために、デバイスのプッシュトークン（例：FCMトークン）および通知設定を保存します。

### 3.7 デバイス情報、診断データ、利用状況データ

- 本サービスの実行に必要なアプリのバージョン、デバイスの種類/OS、言語、その他の技術信号
- デバイスのメタデータやスタックトレースを含むクラッシュおよびパフォーマンスの診断情報（例：Sentry経由）
- セキュリティ、レート制限、不正防止のためにサーバーおよびホスティングプロバイダーが処理するIPアドレスおよびリクエストメタデータ
- オフライン動作のためにデバイス（SQLite / Drift）に保存される旅行データのローカルオフラインコピー

#### 3.7.1 プロダクト分析（お客様の同意がある場合のみ）

プロダクト分析には **Firebase Analytics**（Google）と **Mixpanel** の **2つのプロバイダー** を使用しています。同一のイベントが両方に送信されます。

**分析の収集は、お客様の明示的な同意なしには開始されません。** アプリ初回起動時に確認が表示され、**同意いただくまで両プロバイダーへデータが送信されることは一切ありません。** 同意はいつでも **プロフィール → プライバシーと分析** から取り消すことができ、取り消すとそのデバイスでの収集は停止します。

同意いただいた場合に収集される項目：

- **機能利用イベント** — 例：サインアップ完了（`sign_up_completed`）、オンボーディング完了、旅行作成、AIプラン生成/失敗、ペイウォール表示、購入開始/完了、予約リンククリック、アカウント削除
- **これらのイベントに付随する限定的なコンテキスト** — 例：目的都市名、旅行日数、プラットフォーム（iOS/Android）、登録方法（メール/Google/Apple）、プロダクトID。**旅行コンテンツのテキスト、メモ、プランナーとのチャット内容は送信しません。**
- **自動セッションイベント** — Mixpanel SDKは、アプリセッションの開始/終了、初回起動、アプリアップデートなどの標準イベントも収集します。
- **アカウント識別子** — ログイン時、イベントが同一ユーザーのものであることを識別するために、システムが生成したアカウントID（UUID）が分析プロバイダーに送信されます。**氏名、メールアドレス、プロフィール写真は分析プロバイダーに送信されず**、プロバイダー内でお客様のユーザープロファイルを作成することはありません。ログアウト時にこの関連付けはリセットされます。

Mixpanelのデータは**欧州連合（EU）内のサーバー**で処理・保存されます。

分析プロバイダーを**広告配信やアプリ・サイトをまたぐ追跡に使用することはありません**。

### 3.8 支払いおよび利用権限（有効化されている場合）

サブスクリプションまたはアプリ内購入を行った場合、支払いはApple、Google、および/またはRevenueCatによって処理されます。当社は機能解放に必要な利用権限/ステータスのみを受け取り、クレジットカード番号全体を**受け取ることはありません**。

### 3.9 サードパーティログイン（選択された場合）

GoogleまたはAppleでサインインした場合、Journeoアカウントの作成またはリンクのために、これらのプロバイダーから共有される限定的な情報（プロバイダー設定に基づく識別子、メールアドレス/氏名）を受け取ります。

### 3.10 当社が**販売しない**情報

当社はお客様の個人データを**販売しません**。連絡先リストや旅行コンテンツをデータブローカーに貸与することもありません。

## 4. 個人データの利用目的

個人データを以下の目的で利用します：

1. **サービスの提供** — アカウント作成、本人確認、旅行データの保存・同期、地図や旅程の表示、旅行メンバーや友人との共同作業
2. **AI旅行プランおよび関連コンテンツの生成** — 構造化された旅行プランを作成するAIモデルプロバイダーを呼び出すバックエンドに関連するコンテキストを送信、場所の確認、キャッシュ管理下での都市カバー/アイコン画像の生成
3. **パーソナライズ** — 好み、言語設定、タイムゾーン、旅行条件の適用
4. **コミュニケーション** — 取引メッセージや（同意に基づく）プッシュ通知の送信
5. **信頼性とセキュリティの向上** — 診断、デバッグ、不正利用の防止、レート制限
6. **プロダクト利用状況の測定** — どの機能が役立っているかを把握するための分析（**分析同意をいただいた場合のみ実施**、セクション3.7.1）
7. **アフィリエイト帰属** — パートナーが紹介を追跡できるよう予約リンクのオープンを記録
8. **法的義務の遵守** — 法的要請への対応、利用規約の執行、権利と安全の保護
9. **ご要望への対応** — データのエクスポート、アカウント削除、設定の更新

**法的根拠（GDPR/KVKK適用地域）：** 契約の履行、同意（位置情報、マイク、カメラ、通知、**プロダクト分析**などの任意権限）、正当な利益（セキュリティ、不正防止、エラー診断）、法的義務。

## 5. AIによる処理

Journeoは、旅行日程の作成や調整、および限定的な都市画像生成のためにAIを利用しています。

- AIリクエストは、お客様の端末から直接ではなく、**当社のサーバー**から安全に実行されます。
- 入力データには、目的地、日程、好み、プランナーチャットの内容が含まれる場合があります。
- AIプロバイダーは結果を返すためにプロンプト/応答を処理します。AIの出力を広告プロファイルの作成に使用することはありません。
- **プランナーチャットやAIプロンプトは分析プロバイダーに送信されません。**

AIの提案には誤りが含まれる可能性があります。重要な旅行情報は必ずご自身でご確認ください。

## 6. データの共有

個人データは以下の場合にのみ共有されます：

### 6.1 サービスプロバイダー（処理者）

| カテゴリ | プロバイダー例 | 目的 |
|---|---|---|
| バックエンド / データベース / 認証 | Supabase (Postgres, Auth, Storage) | アカウント、旅行データ、同期、アバター、画像 |
| ホスティング | Google Cloud Run (およびGoogle Cloudインフラ) | APIホスティング |
| 音声ストレージ / CDN | Cloudflare R2 | スポット音声ガイド用音声ファイルのキャッシュ |
| 地図 | Mapbox | 地図表示、スタイル、オフライン地図 |
| スポット | Google Places API (サーバー側) | スポット確認 / 解決（キャッシュ優先） |
| AIモデル | Google Gemini | 旅行プラン生成 |
| 画像生成（限定的） | fal.ai | 都市カバー画像（サーバー側、キャッシュ） |
| パブリック画像ソース | Wikipedia / Wikimedia | スポットまたは目的地の画像 |
| 天気 | Open-Meteo | 旅行日程の天気予報 |
| 分析（**同意時のみ**） | Firebase Analytics (Google) | プロダクト分析 |
| 分析（**同意時のみ**） | Mixpanel — **EUデータ地域で処理** | プロダクト分析、ファネルおよび継続率分析 |
| クラッシュ監視 / オブザーバビリティ | Sentry | クラッシュおよびエラー監視 |
| プッシュ通知 | Firebase Cloud Messaging | プッシュ通知配信 |
| 決済（有効時） | Apple / Google / RevenueCat | アプリ内課金およびサブスクリプション管理 |
| 提携パートナー | Booking, Kiwi, Skyscanner, Viator など | 予約/旅行パートナーリンクをクリックした際 |

### 6.2 お客様が交流を選択した他のユーザー

フレンドを追加したり、旅行を共有した場合、他のメンバーはお客様のプロフィール情報や旅行内容を閲覧できます。**リアルタイム位置情報共有**（セクション3.3）を有効にした場合、アクティブなセッション中のみ同行者が現在地を確認できます。

### 6.2.1 安全レポートとブロック

悪質なユーザーをアプリ内で**ブロック**および**通報**できます。

### 6.3 法的要請および安全性

法律の要請、またはJourneo、ユーザー、公衆を危害や不正から保護するために開示する場合があります。

### 6.4 事業譲渡

合併、買収、資産売却の際、適切な保護措置のもとで個人データが移転される場合があります。

### 6.5 個人情報の不販売

当社は米国州法で定義される個人情報の販売を行いません。

## 9. データの保持

- **アカウントデータ** — アカウントが有効な期間
- **旅行・共同作業データ** — サービス提供に必要な期間
- **キャッシュ** — 運用上の有効期限（TTL）に基づく

アカウントを削除した場合（セクション11）、保持義務のあるデータを除き、個人データを削除または匿名化します。共有旅行については、旅行の消失を防ぐため所有権が他のメンバーに移転される場合があります。
