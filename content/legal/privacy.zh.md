## 1. 我们是谁

本隐私政策由 **Journeo**（“**Journeo**”、“**我们**”或“**我们的**”）发布。

Journeo 是一款适用于 iOS 和 Android 的 AI 辅助、以地图为核心的旅行规划应用程序，以及在 https://journeo.ai 提供的相关服务（统称为“**服务**”）。

本隐私政策说明了我们收集哪些个人数据、如何使用这些数据、与谁共享、保留多长时间以及您拥有的选择。本政策适用于 Journeo 移动端应用、我们的 API 以及我们的网站。

如果您不同意本政策，请不要使用本服务。

## 2. 适用范围与角色

我们作为**数据控制者**，负责处理为提供 Journeo 账户、行程、偏好和相关功能而处理的个人数据。

某些数据处理是由按照我们的指示行动的数据处理方执行的（例如托管、身份验证、分析、崩溃报告、地图和 AI 模型提供商）。这些处理方在第 6.1 节中进行了说明。

本政策旨在满足以下平台的披露要求：

- Apple App Store（隐私政策 URL 与 App 隐私营养标签）
- Google Play（隐私政策 URL 与数据安全表单）
- 适用的隐私法律，包括欧盟/英国 GDPR 和土耳其 KVKK（如适用）

## 3. 我们收集的个人数据

我们仅收集运营 Journeo 所必需的数据。根据您使用服务的方式，可能包括：

### 3.1 账户与个人资料信息

- 电子邮箱地址（您的密码仅以哈希加密形式存储；我们绝不会看到您的明文密码）
- 用户名（唯一，用于查找和添加好友）
- 显示名称 / 全名
- 个人资料头像（Avatar）
- 时区
- 首选语言 / 地区设置
- 由我们系统生成的账户标识符

### 3.2 您创建的行程与内容

- 行程标题、目的地（城市/国家）、日期、封面图片和行程状态
- 旅行偏好（风格、节奏、饮食、预算层级、兴趣爱好、无障碍设置）
- 行程天数与停靠点（您添加的地点、备注、顺序、预订相关链接）
- 行李清单、添加的航班和旅行费用
- 好友关系 / 行程成员与角色（所有者、编辑者、查看者）
- 您为生成或优化行程而发送的规划器聊天消息与提示词（prompts）
- 当您打开我们生成的合作伙伴预订链接时的推广点击事件

### 3.3 位置数据

在获得您的授权后，**在您使用应用程序期间**，我们可能会收集设备的大致和/或精确位置，用于以下目的：

- 在地图上显示您的位置
- 根据您当前所在位置定制行程规划
- 支持语音规划的城市检测等辅助功能
- **与同行伙伴实时共享位置** — 仅在**您主动发起**限时实时共享会话时（例如 1 / 4 / 8 小时或至当天结束）。当该会话处于活动状态且应用在前台运行时，您的坐标将对**该行程**的其他成员可见。当您关闭共享、会话过期或应用转入后台时，共享立即停止。我们**不会**为此功能请求“始终允许”或后台位置权限，也不会与非成员或出于广告目的共享您的实时位置。

我们围绕**使用期间**访问和合理精度设计位置功能。我们**绝不会**为了广告目的在后台持续跟踪您的位置。

您可以在设备设置中拒绝或撤回位置权限。

**您的位置数据不会发送给我们的分析提供商。** 分析事件中最多只包含地点名称（如行程目的地城市，见第 3.7 节），绝不包含具体经纬度坐标。

### 3.4 麦克风与语音

在获得您的授权后，我们可能会访问麦克风和设备/系统语音识别功能，以便您通过语音规划行程。音频仅用于将语音转换为文本以进行规划；我们绝不出售语音录音用于广告。

### 3.5 相机与照片图库

在获得您的授权后，我们可能会访问相机或照片图库以供您设置个人头像。您选择的照片可能会上传到我们的存储空间并关联至您的账户。

### 3.6 通知

如果您启用通知，我们将存储设备推送令牌（如 FCM 令牌）和通知偏好设置，以便发送行程提醒和产品通知。

### 3.7 设备、诊断与使用数据

- 运行服务所需的应用程序版本、设备类型 / 操作系统、语言及类似技术信号
- 崩溃与性能诊断（例如通过 Sentry），可能包含设备元数据和堆栈追踪
- 服务器和托管服务商为确保安全、限流和防范滥用而处理的 IP 地址与请求元数据
- 存储在您设备上的本地离线行程副本（SQLite / Drift），以支持离线使用

#### 3.7.1 产品分析（仅在获得您明确同意的情况下）

我们使用**两家提供商**进行产品分析：**Firebase Analytics**（Google）与 **Mixpanel**。相同事件会同时发送给两者。

**未经您的明确许可，不会开始收集分析数据。** 您在首次打开应用时会收到授权提示；**在您授予权限之前，不会向任何分析商发送任何数据。** 您可以随时在 **个人资料 → 隐私与分析** 中撤回权限；撤回后，该设备上的数据收集将立即停止。

在获得许可后，可能会收集：

- **功能使用事件** — 例如完成注册（`sign_up_completed`）、完成新手引导、创建行程、生成/失败 AI 行程、查看付费墙、发起/完成购买、点击预订链接、删除账户
- **附加在这些事件上的有限上下文** — 例如目的地城市名称、行程天数、平台（iOS/Android）、注册方式（邮箱/Google/Apple）、产品 ID。**我们绝不发送您的行程内容文本、备注或规划器聊天记录。**
- **自动会话事件** — Mixpanel SDK 还会收集标准会话事件（应用启动/结束、首次打开和版本更新）。
- **您的账户标识符** — 登录后，系统生成的账户 ID（UUID）将发送至分析提供商以将事件关联至同一用户。**您的姓名、邮箱地址或头像绝不会发送给分析提供商**，我们也不会在这些平台建立您的个人画像。注销登录后，该关联将被重置。

Mixpanel 数据在**位于欧盟（EU）的服务器**上进行处理与存储。

我们绝不使用分析工具**投放广告或跨应用/跨网站追踪您**。

### 3.8 支付与权益（启用时）

如果您购买订阅或应用内解锁，支付由 Apple、Google 和/或 RevenueCat 处理。我们仅接收解锁功能所需的权益/订阅状态；我们**绝不会**接收您的完整支付卡号。

### 3.9 第三方登录（当您选择时）

如果您使用 Google 或 Apple 登录，我们将接收这些提供商根据您的设置共享的有限账户信息（通常为标识符和邮箱/姓名），用于创建或关联您的 Journeo 账户。

### 3.10 我们**不销售**的信息

我们**绝不销售**您的个人数据。我们不会将您的通讯录或行程内容出租给数据经纪商。

## 4. 我们如何使用个人数据

我们将个人数据用于以下目的：

1. **提供服务** — 创建账户、验证身份、存储与同步行程、展示地图与行程、支持好友协作
2. **生成 AI 行程及相关内容** — 将行程偏好上下文发送至调用 AI 模型的后端以生成结构化计划；核对地点；在受控缓存管道下生成城市封面/图标
3. **个性化** — 应用您的偏好、语言区域、时区和旅行设置
4. **沟通** — 发送事务性消息和推送通知（需授权）
5. **提升可靠性与安全性** — 诊断排错、防范欺诈与滥用、请求限流
6. **衡量产品使用情况** — 聚合分析以了解哪些功能受欢迎（**仅在您授权分析权限后执行**，第 3.7.1 节）
7. **推广归因** — 记录预订链接的打开以归属推荐；支持我们的业务模式
8. **遵守法律** — 响应法律请求、执行条款、保护权益与安全
9. **满足您的请求** — 数据导出、账户注销、偏好更新

## 5. 人工智能（AI）处理

Journeo 使用人工智能协助生成与优化旅行路线。

- AI 请求从**我们的服务器**安全发起，而非从您的设备直接暴露 API 密钥。
- 输入可能包含您提供的目的地、日期、偏好及规划对话内容。
- AI 服务商根据协议处理请求，我们不会使用 AI 输出创建关于您的广告画像。
- **您的规划聊天与 AI 提示词绝不会发送给分析提供商。**

AI 建议可能存在误差，请务必独立核实关键旅行信息。

## 6. 数据共享

我们仅在以下情况下共享个人数据：

### 6.1 服务提供商（处理方）

| 类别 | 示例服务商 | 目的 |
|---|---|---|
| 后端 / 数据库 / 认证 | Supabase (Postgres, Auth, Storage) | 账户、行程数据、同步、头像、图片 |
| 托管服务 | Google Cloud Run 及相关 Google Cloud 设施 | API 托管 |
| 音频存储 / CDN | Cloudflare R2 | 语音导览音频缓存 |
| 地图 | Mapbox | 地图、样式、离线地图工具 |
| 地点 | Google Places API（服务端） | 地点验证 / 解析（优先缓存） |
| AI 模型 | Google Gemini | 行程规划生成 |
| 图像生成（有限） | fal.ai | 城市封面图像（服务端缓存） |
| 公共图片资源 | Wikipedia / Wikimedia | 景点或目的地图片 |
| 天气 | Open-Meteo | 旅行日期的天气预报 |
| 分析（**需授权**） | Firebase Analytics (Google) | 产品分析 |
| 分析（**需授权**） | Mixpanel — **在欧盟数据区处理** | 产品分析与留存分析 |
| 崩溃监控 | Sentry | 崩溃与错误监控 |
| 推送通知 | Firebase Cloud Messaging | 推送发送 |
| 支付（启用时） | Apple / Google / RevenueCat | 应用内购买与订阅管理 |
| 推广合作伙伴 | Booking, Kiwi, Skyscanner, Viator 等 | 当点击预订链接时 |

### 6.2 您选择互动的其他用户

添加好友或共享行程时，其他成员可查看您的公开资料和行程内容。开启**实时位置共享**时，同伴仅在活动会话期间可见您的位置。

### 6.2.1 安全举报与拉黑

您可以随时在应用内**拉黑**用户并**举报**不良行为。

### 6.3 法律与安全要求

依法或为保护 Journeo、用户和公众免受欺诈和安全威胁时，我们可能会披露必要信息。

### 6.4 业务转让

如发生合并、收购或资产出售，个人数据可能在相应保护措施下进行转让。

### 6.5 不得出售个人信息

我们绝不出售个人信息，也不进行跨应用广告追踪。

## 9. 数据保留

- **账户数据** — 在您的账户有效期间保留

注销账户时（第 11 节），除法律要求保留的数据外，我们将删除或匿名化您的个人数据。在共享行程中，为避免行程丢失，所有权可能会转移给其他成员。
